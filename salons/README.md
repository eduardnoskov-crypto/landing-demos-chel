## Что взяли из референсов

- **Один сильный первый экран.** Крупный заголовок, реальный рейтинг, фотография, понятная кнопка записи.
- **Фото — главный носитель стиля.** Не стоковые «улыбки», а работы салона из открытой карточки 2ГИС.
- **Разные композиции, а не один шаблон с разными цветами.** Editorial, dark luxury, pop poster, magazine cover, brutalist grid.
- **Данные вместо вымысла.** Рейтинг, число отзывов, адрес, телефон, часы и стартовые цены — из карточки 2ГИС. Где цены не было — не придумывали.
- **Один CTA на каждом экране.** Позвонить или открыть 2ГИС; на мобильном — закреплённая панель.

## Технически

- Чистый HTML/CSS/JS, без сборки и внешних библиотек.
- Адаптив: 390 px, 760 px, 980 px, 1440 px.
- Лайтбокс с клавиатурой, `Esc`, стрелками.
- `prefers-reduced-motion`, видимый фокус, семантические заголовки.
- Изображения локальные, оптимизированы; исходные URL и права — в `photos_manifest.json`.
- Футер каждой страницы: «Демонстрационная страница по открытым данным 2ГИС. Не является официальным сайтом…»
